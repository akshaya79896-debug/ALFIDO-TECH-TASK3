
# 🌌 CosmoExplorer – Space Data Visualization Platform

A responsive and interactive web application that integrates multiple NASA Open APIs to display real-time space data, astronomy images, and scientific information. The application allows users to explore the universe through NASA's daily astronomy picture, searchable space images, featured space galleries, and near-Earth asteroid data.

---

## 🎯 Objective

The objective of this project is to demonstrate API integration using JavaScript Fetch API by retrieving live scientific data from NASA Open APIs and displaying it dynamically on a web page. This project was developed as part of my Frontend Developer Internship task to strengthen my understanding of REST APIs, asynchronous JavaScript, JSON handling, and dynamic user interfaces.

## 🛰️ APIs Used

### 🌠 NASA Astronomy Picture of the Day (APOD) API
Provides NASA's daily featured astronomy image or video along with a scientific explanation.

### 🔍 NASA Image and Video Library API
Allows searching NASA's extensive collection of space-related images.

### ☄️ NASA Near Earth Object (NEO) API
Provides real-time information about asteroids currently passing near Earth.

---

## 📝 Short Write-Up on API Used

An API (Application Programming Interface) is a set of rules that allows one software application to communicate with another. APIs provide data or services that developers can integrate into their applications.

This project uses NASA Open APIs, which are publicly available REST APIs that provide real-time scientific data and images. The APIs return data in JSON format, which is fetched using JavaScript's Fetch API and dynamically displayed on the webpage.

These APIs make the application dynamic, educational, and visually engaging.

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Add your NASA API key in `script.js`.
4. Open `index.html` in any modern web browser.
5. Start exploring the universe.

---

## 🔑 How to Get NASA API Key

1. Visit [https://api.nasa.gov](https://api.nasa.gov)
2. Click on **Generate API Key**
3. Register using your email address
4. Copy the generated API key
5. Replace the following line in `script.js`:

```javascript
const API_KEY = "YOUR_NASA_API_KEY";
```
